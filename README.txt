Forex position calculator (PWA) - update package

This zip does NOT contain config.js on purpose, so uploading it will not overwrite
your Firebase settings. Upload all the files in this folder to your GitHub repo
(Add file > Upload files), replacing the old ones, and leave your existing config.js alone.

First-time setup (new repo): also create config.js as described in SETUP.txt.
Wait 1-2 minutes for GitHub Pages, then open the app online.
