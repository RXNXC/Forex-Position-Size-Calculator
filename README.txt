Forex position calculator (PWA) - update package

HOW TO UPDATE (same as before)
1. In your GitHub repo choose Add file > Upload files.
2. Drag in everything from this zip: index.html, sw.js, manifest.webmanifest, the three icon PNGs,
   firestore.rules, SETUP.txt, README.txt and the whole "images" folder.
3. DO NOT upload a config.js from this zip (there is none, on purpose). Keep your own config.js
   with your Firebase values. If it is missing the app tells you exactly which values are absent.
4. Commit, wait 1-2 minutes for GitHub Pages, open the app online, close it fully and reopen it once.

FIRST-TIME SETUP: follow SETUP.txt (Firebase) and create config.js as described there.
